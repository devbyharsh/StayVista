StayVista — Full-Stack Airbnb-Style Web Application

A full-stack accommodation listing platform built while learning the Node.js/Express/MongoDB stack. The project includes user authentication, listing CRUD operations, reviews, image uploads, authorization, validation, maps, and database relationships.

Tech stack:
Node.js • Express.js • MongoDB • Mongoose • EJS • JavaScript • Bootstrap • Passport.js • Cloudinary • Mapbox

Key features:

🔐 User signup/login/logout,
🏠 Create, edit and delete listings,
⭐ Reviews and ratings,
👤 Authentication & authorization,
📸 Cloudinary image uploads,
🗺️ Mapbox location/maps,
🗄️ MongoDB database,
🛡️ Server-side validation,
⚠️ Error handling,
📱 Responsive UI.
